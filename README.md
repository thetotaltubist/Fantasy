# Fantasy HQ

A private website that pulls in your fantasy football leagues and (later) gives start-sit, waiver and trade advice.

## Status
- Sleeper: working. Enter a Sleeper username to see leagues, records and rosters.
- ESPN, Yahoo, projections, start-sit, waivers and trades: coming next.

## Run it locally
```
npm install
npm run dev
```
Then open http://localhost:3000.
